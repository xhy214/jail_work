改了背景才变，还是原样输入也会变？

同一请求只改单个因素，再加入完全相同输入的两次独立调用作为对照。比较两类不一致，而不直接把任何差异归因于背景。

每轮四次调用

① 原样 / 变更

请求与系统政策保持相同，显示主题或页面标题一次只改一项。测量变更前后判定是否一致。

② 原样 / 原样

完全相同请求再独立执行两次，测量模型本身的随机波动。调用顺序与实验块顺序均随机化。

③ 重复与记录

每个条件重复12轮作演示。记录请求哈希、响应、失败和时间；四次都完成才纳入比较。

立即运行

python3 -m boundarycheck plan --config examples/boundary_demo.json
python3 -m boundarycheck run --config examples/boundary_demo.json \
  --mode mock --output runs/boundary-demo
python3 -m unittest discover -s tests -v

只用Python标准库。示例计划192次调用，mock模式不访问网络。内置模拟差异是人工设定的测试夹具，不是实际模型的行为发现。

真实模型接入

沿用旧RL包的TARGET_API_BASE、TARGET_MODEL与TARGET_API_KEY配置名称；密钥通过环境安全注入。使用明确的--mode live执行，保留TLS验证。没有配置时会报错，不会静默变成模拟运行。

原始交互保存在本地被忽略的runs目录。输出包括SQLite、聚合JSON和Markdown报告。运行失败与中断单独记录，不算作模型安全响应。
