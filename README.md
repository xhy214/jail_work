# 阶段成果汇报页

这是一个可直接由 GitHub Pages 发布的静态汇报站点。页面聚焦提示词组合器和老虎机优化，包含安全示例组合器、探索趋势图、固定组合验证图与研究限制说明。无需构建步骤、依赖安装或外部 CDN。

## 部署步骤

1. 解压本压缩包，把 **index.html**、**README.md** 和 **.nojekyll** 放入 GitHub 仓库的发布源目录根部。
2. 将文件提交到仓库的 **main** 分支。
3. 打开仓库 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**，分支选择 **main**，目录选择 **/(root)**，然后保存。
5. 等待发布完成，在 Pages 设置页打开站点链接。

页面入口必须位于发布源目录根部。若改用 **docs** 目录发布，请把三个文件放到 **docs/**，并在 Pages 设置中选择 **/docs**。

## 汇报版说明

- 组合器交互区使用无害的演示元件；真实实验的任务载荷和具体组合未放入页面。
- 图表使用匿名批次标签。平均分、阈值占比和拒答率基于压缩包内数据库的已完成记录复算；每 100 轮窗口图不包含不足 100 个样本的尾段。
- 组合器配置为 schema 5.8.0，优化实验使用 schema 5.9.0。页面已将这一版本差异列为复现限制。
- GitHub Pages 页面可通过站点链接公开访问。发布前请再次检查仓库和页面中适合公开展示的内容。
