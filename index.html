TRANSFER

迁移结果需要独立确认

部分迁移验证接近原确认表现，另一些明显回落。单次迁移结果不足以证明可泛化，需要更多重复实验与置信区间。

解读评分：本页展示的是实验自定义的综合分。高分只代表更符合该实验评分目标，不等同于模型整体质量或系统安全水平；需同时查看拒答率、样本量、失败率与人工审查结果。

版本对齐

随包组合器配置为 schema 5.8.0，优化实验使用 schema 5.9.0。网页统计仅纳入可从随包数据库复算的批次；后续应统一 schema 与报告口径。

比较边界

部分运行处于不同时间窗口，API 失败率也有差异。均分仅对成功完成的评测计算，无法替代跨时段、同条件的对照实验。

PUBLISH / GITHUB PAGES

部署为静态汇报页

页面只有 HTML、CSS 与内嵌 JavaScript，无需安装依赖或运行构建命令。将 index.html 放在发布源目录根部即可。

  1. 解压下载包，将 index.html、README.md 和 .nojekyll 放到 GitHub 仓库根目录。
  2. 打开仓库 Settings → Pages，在 Build and deployment 中选择 Deploy from a branch。
  3. 发布源选择 main 分支与 /(root)，保存后等待 GitHub Pages 完成发布。
  4. 分享前预览站点，并确认内容适合公开访问。
